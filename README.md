One line, in the voice of the Moon, answering at last every wish, howl and
late-night promise ever aimed at it.

> Four billion years of howls, wishes, and promises. Every single one was about someone who never texted back.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
